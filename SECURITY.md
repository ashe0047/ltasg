# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/ashe0047/ltasg/security/advisories/new). Do not open a public issue or include exploit details in a pull request.

Include the affected version, a concise description, reproduction steps, and any suggested mitigation. The maintainer will acknowledge the report and coordinate disclosure after a fix or mitigation is available.

## Supported versions

Only the latest published version receives security fixes. Upgrade to the latest release before reporting an issue that may already be resolved.

## Secret handling

Never commit LTA API keys, PyPI tokens, or other credentials. If a credential is exposed, revoke it immediately with the issuing service and report the incident privately.
