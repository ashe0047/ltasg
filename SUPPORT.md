# Support

Use [GitHub Issues](https://github.com/ashe0047/ltasg/issues) for reproducible bugs and feature requests.

Before opening an issue:

- check the [README](README.md) and the [LTA DataMall API User Guide](https://datamall.lta.gov.sg/content/dam/datamall/datasets/LTA_DataMall_API_User_Guide.pdf?ref=public_apis);
- search existing issues;
- remove API keys and other secrets from logs and examples;
- include the package version, Python version, operating system, endpoint, and a minimal reproduction.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
